# DSH Private

[English](guide.md) | 中文

## 变更

DSH Private 使用独立的应用标识，数据目录默认为 `~/.dsh-private`，不导入官方版或 NEXT 的凭据、插件和历史。账户登录、设备注册、会话上传、产品统计、匿名追踪标识和后台更新的实现已移除。本地会话文件和崩溃日志保留在本机。

官方 API Key 模型供应商初始未启用，支持添加、删除和重新添加。模型和搜索供应商均不预设。保存模型选择前，模型目录返回 `default: null`。`agentDefaultModel.currentSelection()` 要求已配置模型；需要显示空状态的调用方使用 `configuredSelection()`。

官方 API Key 搜索、直接 HTTP 网页读取、依赖下载和插件管理继续可用。搜索地址独立于聊天地址配置。账户专属的钱包和额度功能不再提供。已配置的服务请求仍携带必要的鉴权和任务数据。第三方插件可能具有额外的联网行为。

## 迁移

1. 将 DSH Private 与原客户端并存安装，打开独立工作区。
2. 在模型设置中添加自定义供应商或官方 DeepSeek API Key 供应商，再选择模型。删除当前供应商会清除默认选择，不会自动切换至其他服务。
3. 在网页搜索设置中明确选择并配置搜索供应商。聊天网关只有支持所选搜索接口才能同时承担搜索。直接 HTTP 网页读取独立可用。
4. 模型密钥和用户数据保留在本机，GitHub 构建不需要模型密钥或旧客户端文件。
5. 后续通过本仓库 DSH Private macOS 工作流提供的安装包手动升级，核对 SHA256 和记录的源码提交。
